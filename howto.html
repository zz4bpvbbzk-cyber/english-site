📖 使用說明（給老師）

這個網站怎麼運作？

整個網站只有「一個課程資料檔」＋「幾個頁面模板」。所有課程內容都寫在 lessons.js 裡，瀏覽器打開頁面時會自動把資料變成漂亮的網頁。所以：以後想新增課程，只要編輯 lessons.js 一個檔案就好，不用寫任何網頁程式。

怎麼開啟網站？

  1. 把整個資料夾下載解壓縮。
  2. 雙擊 index.html 就能在瀏覽器開啟（離線也能用）。
  3. 想讓家長或學生線上瀏覽：把整個資料夾上傳到 GitHub Pages 或 Netlify（免費），就會得到一個網址。

怎麼新增一節課？

用記事本（或 VS Code）打開 lessons.js，找到你要新增課程的那個學期（例如 g1a 是一上），在它的 lessons: [ ... ] 陣列裡，複製一筆現有的課程物件，貼在最後一筆的後面（記得上一筆結尾要有逗號），再修改內容即可。

每一節課固定有這幾個欄位（對應你設計的四段式教學）：

{
  id: "a",            // 唯一代號（不能重複，用英文或數字）
  no: "第 2 課",       // 課次
  title: "Letter A",  // 課名
  tag: "Aa",          // 標籤（例如字母）
  sound: "/æ/",       // 發音
  focus: "字母 Aa 的…", // 本課重點（會顯示在列表）
  objectives: ["…"],   // 教學目標
  warmup: {           // ① 打招呼・熱身
    song: { name: "…", url: "https://www.youtube.com/watch?v=…" },
    activity: "活動說明"
  },
  main: {             // ② 主要學習內容
    intro: "…",
    uppercase: "大寫筆順說明",
    lowercase: "小寫筆順說明",
    vocab: [ { en: "apple", zh: "蘋果" } ],
    chant: "A, a, apple!"
  },
  song: { name: "…", url: "https://www.youtube.com/watch?v=…" }, // ③ 歌曲
  game: { name: "遊戲名", rules: "遊戲規則" },                     // ③ 遊戲
  worksheet: { name: "學習單名", description: "學習單說明" }       // ④ 學習單
}

怎麼找 YouTube 影片連結？

在 YouTube 搜尋「Super Simple ABCs The A Song」之類的關鍵字，複製網址列「watch?v=…」的完整網址貼到 url 欄位即可。建議用 Super Simple ABCs 的字母歌（每課一首，約 40 秒，最適合低年級）。

列印學習單

打開某一課的頁面，按右下角「🖨 列印本課教案」，就會印出乾淨的教案（不含按鈕和選單），可以直接放進教案本。

想改網站名稱或顏色？

在 lessons.js 最上面的 SITE 可以改網站標題；每個學期的 color 可以改卡片顏色。
